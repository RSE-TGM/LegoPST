LegoPST

Ambiente di simulazione e controllo di processi termici, idraulici ed elettrici. Il comando lgrun lo fa girare dentro un container Docker: sulla macchina non si installa LegoPST.

Installazione

Serve Docker (o Podman) funzionante. Poi:

curl -fsSL https://rse-tgm.github.io/LegoPST/install | bash

Apri un nuovo terminale (o source ~/.bashrc) e lancia lgrun. La prima volta Docker scarica l'immagine: qualche GB, una volta sola.

Altro

lgrun --help       tutte le opzioni
lgrun -update      aggiorna lgrun e l'immagine
lgrun -uninstall   disinstalla (i tuoi dati restano)

Lo script che viene eseguito: install, che a sua volta scarica docker/install_legopst_dock.sh. Repository: github.com/RSE-TGM/LegoPST.
