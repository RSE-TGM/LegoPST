LegoPST

A simulation and control environment for thermal, hydraulic and electrical processes. The lgrun command runs it inside a Docker container: nothing of LegoPST gets installed on your machine.

Installation

You need a working Docker (or Podman). Then run:

curl -fsSL https://rse-tgm.github.io/LegoPST/install | bash

Open a new terminal (or run source ~/.bashrc) and start lgrun. The first time, Docker downloads the image: a few GB, only once.

More

lgrun --help       all the options
lgrun -update      update lgrun and the image
lgrun -uninstall   uninstall (your data is kept)

The script that gets run: install, which in turn downloads docker/install_legopst_dock.sh. Repository: github.com/RSE-TGM/LegoPST.
